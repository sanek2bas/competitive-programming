# Примеры для знакомства с моделями контроля доступа

## Overview

Популярные модели управления доступом, когторые определяют, кто и какие действия может совершать с ресурсами в информационных системах.

RBAC (Role-Based Access Control) — это управление доступом на основе ролей. Права привязываются к ролям, а пользователи получают эти права через назначение им конкретной роли.

ABAC (Attribute-Based Access Control) — это разграничение доступа на основе атрибутов. Решение принимается динамически на основе набора характеристик: атрибутов пользователя, ресурса (гриф секретности, владелец), действия и контекста.
